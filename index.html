How to use the demo

  1. Swipe the space bar left or right to switch English, প্রভাত (Probhat) and অভ্র (Avro). Hold it for the language list.
  2. Hold a key for its variants, then slide onto one and release. Try র, ক or ন in Probhat.
  3. Type in Avro: switch to অভ্র and write ami bhalo achi. Tap a suggestion to complete a word.
  4. Toolbar: clipboard, text editing, settings, theme and voice. ?123 opens the symbol pages.
  5. On a computer type on your real keyboard. Ctrl+Z / Y undo and redo, Ctrl+A / C / V select, copy, paste. Esc closes panels.

Features

04 / Inside
অ

Bengali suite

Avro phonetic (ami becomes আমি), Probhat with long-press shifts, and Jatiyo with full conjunct support.

Dynamic bubbles

Key previews inherit the tint of the key beneath them, plus the Constellation Web typing animation.

Haptic engine

Crisp feedback tuned for linear motors.

Gesture typing

Glide trace input with real-time word formation.

Clipboard

History with pinned items, one-handed mode, split tablet layout and adjustable height.

On-device by design

Typing, prediction and Whisper voice input run on the device. No analytics SDKs. The only network use found in the public source is the update check against GitHub.
